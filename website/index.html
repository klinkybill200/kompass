Why we build Kompass

The most powerful tool on your Mac shouldn't feel like a minefield.

1

The terminal is scary

A blinking cursor, cryptic commands, no undo. Most people never dare to try – and miss out on how fast and powerful it really is.

2

One typo, gone forever

rm deletes without a Trash. A single > can wipe a file. The classic terminal assumes you already know everything.

3

Kompass changes that

It explains, it protects, it teaches. A real zsh with a friendly co-pilot – and when you have learned enough, it simply gets out of your way.

Our goal: anyone should be able to open a terminal without fear – and enjoy it.

What Kompass does

A real terminal, with a safety net.

🛡️

Command guard

Every line is checked before it runs and rated safe, careful or dangerous. Risky commands get a friendly dialog that says in plain words what will happen.

🗑️

rm goes to the Trash

Deleting is never final. Files land in the macOS Trash, and one click on “Undo” puts them back exactly where they were.

💬

Plain language

Type “find all pdf files” – Kompass turns it into the right command, shows it to you and only runs it on your second Enter. English and German.

🔎

Live explanations

While you type, a bar below the terminal explains every part of the command – flags, files, pipes and redirects.

🩹

Error help

“No such file or directory”? Kompass translates cryptic errors, spots typos and offers the corrected command with one click.

🧭

13 learning missions

From “Where am I?” to scripts and pipes: short guided missions that check your real commands and celebrate your progress.

🗂️

Tabs & shortcuts

⌘T for a new tab in the same folder, ⌘1–9 to jump, ⌘K to clear. Everything you expect from a modern Mac app.

✨

Optional AI

For requests the built-in rules don't know, Kompass can ask Claude – only if you add your own API key. Without it, everything stays on your Mac.

Questions

Is Kompass really free?

Yes. Kompass is freeware – no trial, no subscription, no ads. Donations are welcome but never required.

Does it replace the macOS Terminal?

It can. Kompass runs a real zsh with your own configuration, so all your commands, aliases and tools work as usual – with explanations and a safety net on top.

Is my data sent anywhere?

No. Everything runs locally. Only if you add your own Anthropic API key, requests that the built-in rules don't understand are sent to Claude – together with the folder path and file names of the current folder.

Can I still really delete files?

Yes. The guard dialog has a “Delete permanently” option. By default, though, rm moves files to the Trash so you can always undo.

Is Kompass open source?

Yes. The full source code is on GitHub under the MIT license. Ideas, bug reports and pull requests are very welcome.

Is Kompass safe to install?

Yes. Kompass is signed with an Apple Developer ID and notarized by Apple – macOS checks it before the first start, and it opens without warnings. The full source code is public on GitHub.
